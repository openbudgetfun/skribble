# skribble.dev is lettered in Noto Sketch and shares as a picture

The landing page and the documentation now use Skribble Noto Sketch, skribble's default typeface, for their text and headings. Links to skribble.dev or any docs page now preview as a large card with the page's own title and description and a hand-drawn image of skribble.
