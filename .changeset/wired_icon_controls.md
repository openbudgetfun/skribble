# Adopt rough icons across wired widgets

`WiredIcon` replaces `Icon` for destination and action icons across the library so icon visuals stay consistently hand-drawn: navigation bars, bottom navigation, and navigation rail; combo boxes, expansion tiles, segmented buttons, and input chips; search bars, filter chips, popup menus, and steppers; and context menus, the colour picker, avatar fallbacks, the navigation drawer, dismissible, and reorderable list views — with fallback behaviour preserved for unsupported glyphs.
