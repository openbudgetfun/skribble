# Asset provenance registry.
#
# Every generated visual asset in this repository is built from a source pinned
# here by exact version and checksum. Bumping a source is always an explicit
# edit to this file in the same commit as the regenerated catalog, so a diff
# never hides an upstream change.
#
# Generation is deterministic: the same source bytes plus the same generator
# produce byte-identical output. CI enforces this by re-deriving every catalog
# and failing on any diff. See "Determinism" in docs/asset-provenance.md.

# >>> iconify
# Columns (whitespace separated, read by scripts/generate_iconify_sets.sh):
#   <prefix> <npm-version> <sha256-of-icons.json> <base-codepoint> <SPDX>
#   <dart-package> <display-name> <homepage>
#
# The Dart package name need not match the prefix: Iconify calls the Simple
# Icons set `simple-icons`, which is not a legal Dart identifier, so it ships as
# `skribble_icons_simple`.
#
# Codepoint bands are private-use allocations. Keep them disjoint. The BMP
# private-use area (0xE000-0xF8FF) holds 6,400 codepoints, which the four
# smaller sets fit inside; Simple Icons at 3,460 names does not, so it moves to
# the supplementary private-use plane at 0xF0000.
#
#   lucide       0xE000-0xEFFF   2,056 used
#   bxs          0xF100-0xF3FF     665 used
#   cib          0xF400-0xF7FF     831 used
#   simple       0xF0000-0xF0FFF 3,460 used (supplementary plane)
#   material     upstream Material codepoints, resolved through IconData
